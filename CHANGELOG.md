# Change history

## v2.0.2, 2026-09-09

- Loaded the checkout field through the storefront observer so encapsulated template fallback works with Bootstrap and other installed templates.

## v2.0.1, 2026-09-09

- Corrected the storefront script filename so Zen Cart loads the gift message field during standard checkout, guest checkout, and One Page Checkout.

## v2.0.0, 2026-09-09

- Rebuilt the 2012 customization as an encapsulated Plugin Manager package.
- Removed the need for core file edits and template replacements.
- Added standard checkout, guest checkout, and One Page Checkout support.
- Added configurable field name, directions, placeholder, enabled status, and maximum entry length.
- Added browser and server length enforcement.
- Added confirmation, order email, and admin order display.
- Added safe migration that preserves legacy order messages.
- Added clean uninstall behavior that preserves saved order records.
- Added PHP 8.0 through 8.5 automated syntax checks.

## v1.1, 2012-10-24

- Initial PRO-Webs release for Zen Cart 1.5.0 and 1.5.1.
